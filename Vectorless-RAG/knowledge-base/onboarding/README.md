# Onboarding — FAQ

Start here on day one. Questions new engineers actually ask, in the order they ask them.

**Where do I get access?**
Your manager raises the access request. SSO and Slack on day one; cluster access usually day
two. See `security/access-control.md`.

**How do I run ShopFast locally?**
You mostly don't. See `onboarding/dev-environment.md` — you run the service you're working on
and point it at `dev`.

**Which team owns X?**
`reference/service-ownership.md`. Do not guess, especially before paging someone.

**Something is broken in production. What do I do?**
Do not fix it alone. `incidents/incident-response.md`, and page the right rotation from
`incidents/on-call-rotation.md`.

**Can I deploy on my first week?**
Yes, and you should — a small change, with someone watching. See
`operations/deployments.md`.

**What does SEV-2 mean?**
`incidents/severity-levels.md`.

**What's this error code?**
`reference/error-codes.md`.

**What does that acronym mean?**
`reference/glossary.md`.

**Am I allowed to say "I don't know"?**
Yes. It is much cheaper than guessing. Ask in `#engineering`.
