# First Week Checklist

## Day 1
- [ ] SSO + MFA configured
- [ ] Slack joined: `#engineering`, your team channel, `#incidents`
- [ ] Laptop set up, `ci` CLI installed
- [ ] Read `onboarding/README.md`

## Day 2
- [ ] Cluster access working (`kubectl get pods -n dev`)
- [ ] Run your team's service locally — `onboarding/dev-environment.md`
- [ ] Skim `reference/glossary.md` and `reference/service-ownership.md`

## Day 3
- [ ] Read the runbook for the service you will work on
- [ ] Read `incidents/incident-response.md` and `incidents/severity-levels.md`
- [ ] Read one postmortem — `incidents/postmortem-2026-03-checkout-outage.md` is a good one

## Day 4
- [ ] Open a small PR
- [ ] Get it reviewed and merged

## Day 5
- [ ] **Deploy it to production**, with someone watching
- [ ] Watch the dashboards for 10 minutes afterwards
- [ ] Shadow whoever is on-call for an hour

You are not expected to be useful in week one. You are expected to be able to find things —
which is why so much of this list is reading, not building.
